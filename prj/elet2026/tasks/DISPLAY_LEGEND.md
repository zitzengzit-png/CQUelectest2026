# OLED 显示字段说明

本文档说明 `displayTask` 在 0.96 寸 128×64 OLED 上显示的每一个英文缩写、单位、符号和异常标记。

代码位置：

- 渲染逻辑：`tasks/display_task.c`
- 显示快照结构：`tasks/display_task.h` 中的 `LCD_Data_t`
- 刷新周期：20 Hz（50 ms）
- OLED 接口：I2C3，400 kHz，DMA

> 屏幕是 5×7 ASCII 字体，每行最多 21 个字符。

## 1. 正常显示画面

一个典型画面如下：

```text
POS RUN P250 C50 E0
YAW+012.3 YTG+000.0
PIT+001.2 PT+000.0
YR+000.0 PR-001.2
DST+001234/+001200
SPD+001234/+001200
OUT L+0125 R+0125
L+0012345 R+0012350
```

## 2. 第 0 行：模式、状态、频率、错误

```text
POS RUN P250 C50 E0
```

| 显示 | 全称 | 含义 | 单位/范围 |
|---|---|---|---|
| `POS` | Position | 位置控制模式 | — |
| `SPD` | Speed | 速度控制模式 | — |
| `ATT` | Attitude | 姿态控制模式 | — |
| `STP` | Stop | 停止模式 | — |
| `RUN` | Run | 正在运行 | — |
| `STP` | Stop | 当前处于停止状态 | — |
| `P` | PID | PID 任务实际运行频率 | Hz |
| `C` | Control | controlTask 实际运行频率 | Hz |
| `E` | Error | 错误计数 | 0～9，超过 9 显示 9 |
| `!` | — | IMU 未就绪或数据停更 | — |

示例含义：

```text
POS RUN P250 C50 E0
```

表示：

```text
位置模式
正在运行
PID 实际约 250 Hz
controlTask 实际约 50 Hz
错误计数 0
IMU 正常
```

停止时：

```text
STP STP P250 C50 E0
```

前一个 `STP` 是模式，后一个 `STP` 是运行状态。

### 频率还没准备好

刚上电后的前几个显示周期，会显示：

```text
P--- C---
```

含义：

```text
频率统计窗口还没填满
```

这不是故障，等约 400 ms 后会变成实际频率。

### 错误计数 `E`

`E` 的数字由三部分组成：

```text
IMU UART/DMA 错误
+ OLED I2C 错误
+ PID 发送显示队列失败次数
```

显示只保留一位：

```text
E0 ～ E9
```

超过 9 仍然显示 `E9`。

### 末尾 `!`

如果第 0 行末尾出现：

```text
POS RUN P250 C50 E0!
```

表示：

```text
IMU 未就绪，或 IMU 数据已停更超过 100 ms
```

## 3. 第 1 行：Yaw

```text
YAW+012.3 YTG+000.0
```

| 显示 | 全称 | 含义 | 单位 |
|---|---|---|---|
| `YAW` | Yaw | 当前 yaw 角 | 0.1° |
| `YTG` | Yaw Target | 目标 yaw 角 | 0.1° |

示例：

```text
YAW+012.3 = 当前 yaw 角 +12.3°
YTG+000.0 = 目标 yaw 角 0.0°
```

## 4. 第 2 行：Pitch

```text
PIT+001.2 PT+000.0
```

| 显示 | 全称 | 含义 | 单位 |
|---|---|---|---|
| `PIT` | Pitch | 当前 Pitch 角 | 0.1° |
| `PT` | Pitch Target | 目标 Pitch 角 | 0.1° |

示例：

```text
PIT+001.2 = 当前俯仰角 +1.2°
PT+000.0  = 目标俯仰角 0.0°
```

## 5. 第 3 行：角速度

```text
YR+000.0 PR-001.2
```

| 显示 | 全称 | 含义 | 单位 |
|---|---|---|---|
| `YR` | Yaw Rate | 当前 yaw 角速度 | 0.1°/s |
| `PR` | Pitch Rate | 当前 Pitch 角速度 | 0.1°/s |

示例：

```text
YR+000.0 = yaw 角速度 +0.0°/s
PR-001.2 = Pitch 角速度 -1.2°/s
```

## 6. 第 4 行：距离

```text
DST+001234/+001200
```

| 显示 | 全称 | 含义 | 单位 |
|---|---|---|---|
| `DST` | Distance | 距离 | mm |
| `/` | — | 分隔“当前值 / 目标值” | — |

含义：

```text
当前距离 = +1234 mm
目标距离 = +1200 mm
```

## 7. 第 5 行：速度

```text
SPD+001234/+001200
```

| 显示 | 全称 | 含义 | 单位 |
|---|---|---|---|
| `SPD` | Speed | 速度 | mm/s |
| `/` | — | 分隔“当前值 / 目标值” | — |

含义：

```text
当前速度 = +1234 mm/s
目标速度 = +1200 mm/s
```

> 注意：第 0 行的 `SPD` 是“速度模式”，第 5 行的 `SPD` 是“速度数值”，两者含义不同。

## 8. 第 6 行：左右 PWM

```text
OUT L+0125 R+0125
```

| 显示 | 全称 | 含义 |
|---|---|---|
| `OUT` | Output | 电机输出 PWM |
| `L` | Left | 左轮 |
| `R` | Right | 右轮 |

含义：

```text
左轮输出 PWM = +0125
右轮输出 PWM = +0125
```

`OUT` 是限幅后的有符号 PWM，当前范围约为：

```text
-4199 ～ +4199
```

正负号表示电机转向。

## 9. 第 7 行：编码器累计

```text
L+0012345 R+0012350
```

| 显示 | 全称 | 含义 |
|---|---|---|
| `L` | Left | 左编码器累计计数 |
| `R` | Right | 右编码器累计计数 |

单位：

```text
4 倍频后的编码器计数
```

不是米，也不是脉冲/秒。距离/速度的米制换算已经在 PID 内部完成。

## 10. 等待 PID 数据画面

如果还没有收到 PID 的显示快照，会显示：

```text
WAIT PID DATA
OLED 20HZ
I2C3 400K DMA
```

| 显示 | 含义 |
|---|---|
| `WAIT PID DATA` | 等待 PID 数据 |
| `OLED 20HZ` | OLED 刷新率 20 Hz |
| `I2C3 400K DMA` | OLED 使用 I2C3、400 kHz、DMA 传输 |

## 11. 符号说明

| 符号 | 含义 |
|---|---|
| `+` | 正数 |
| `-` | 负数 |
| `/` | 当前值 / 目标值 |
| `!` | IMU 异常或数据停更 |
| `---` | 数据还没准备好 |

## 12. 容易混淆的缩写

| 缩写 | 出现位置 | 含义 |
|---|---|---|
| `SPD` | 第 0 行 | 速度控制模式（Speed mode） |
| `SPD` | 第 5 行 | 当前/目标速度（Speed） |
| `STP` | 第 0 行模式位置 | 停止模式（Stop mode） |
| `STP` | 第 0 行状态位置 | 当前处于停止状态 |
| `L` / `R` | 第 6 行 | 左/右轮 PWM |
| `L` / `R` | 第 7 行 | 左/右编码器累计计数 |

## 13. 当前屏幕未显示的调试量

以下数据在 `LCD_Data_t` 中有，但当前画面没有显示：

| 字段 | 含义 |
|---|---|
| `loop_time_us` | 最近一次 PID 250 Hz 循环耗时，µs |
| `imu_age_ms` | 距最近一帧 IMU 数据的毫秒数 |
| `timestamp_ms` | 快照生成时刻 |
| `sequence` | PID 发送序号 |
| `target_yaw_rate_0p1dps` | 目标 yaw rate，0.1°/s |

`LP`（Loop Time，PID 循环耗时）之前显示在第 0 行，现在为了显示 `P/C` 频率已经移出屏幕。

## 14. 快速记忆

```text
POS/SPD/ATT/STP = 模式
RUN/STP         = 运行状态
P/C             = PID/controlTask 实际频率
E               = 错误数
YAW/YTG         = 当前/目标 yaw
PIT/PT          = 当前/目标 pitch
YR/PR           = yaw rate / pitch rate
DST             = 距离（mm）
SPD             = 速度（mm/s）
OUT L/R         = 左右 PWM
L/R             = 左右编码器累计计数
```
